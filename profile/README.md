## Four Beats

1. **Name the job.** Title the Pipe Flow Expert loop before you enter lengths.
2. **Pin the live set.** Keep this circuit on the sheet and leave other lines aside.
3. **Check once.** Read pressure drop before you change a diameter.
4. **Close the loop.** Leave the balance note so the next visit starts on the same sheet.

## First Questions

**Does Pipe Flow Expert replace every other program?**  
No. Pipe Flow Expert sits beside drawings and the files you already use.

**Can two people share one computer?**  
Yes. Each person keeps a separate Pipe Flow Expert loop file.

**What should a new user try first?**  
One short closed loop today, then the same sheet tomorrow.

## Field Note

Pipe Flow Expert is easier to trust when the sheet stays smaller than the plant it came from. Name the loop, keep the live pipes, and write which drop still matters. That record is short: not every line in the building, only the path back to this balance.

The same pass fits a lab bench or a plant review. Open the last sheet, finish one size check, and leave fewer loose notes than you found.

## One Real Pass

Pick a loop that already has a name. Open it in Pipe Flow Expert, keep only those pipes, and finish one visible sizing step. Extra circuits wait for their own title.
